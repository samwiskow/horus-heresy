# Story arc source audit

Checked on 1 October 2026.

The old catalogue assigned every book to one of nine manually defined groups.
Names such as "Legions in collision", "Loyalist convergence", and "The Warmaster
ascendant" had no recorded source memberships. The same groups appeared in the
Reference and Black Library Saga options.

## References checked

[Daunt's series-order flowchart](https://www.kylebb.com/HH/HHSeriesOrder.svg) is
the authority for the Reference option's arrows. The existing source snapshot
is version 0.9, modified on 2 July 2019. Its embedded draw.io document provides
book titles, positions, styles, and connections. Its key describes publication
formats. It does not provide explicit named arc membership records or
book-to-arc attributes.

[The interactive timeline](https://gaming.kylebb.com/hhtimeline/) explains the
author's focus on major story arcs. On the audit date it embedded a draw.io
document modified on 15 February 2024, still titled version 0.9. That document
has 449 cells: 240 vertices, 207 edges, and two root cells. Its vertices share
the top-level parent and have no tags or explicit arc membership attributes.
It shows coloured branches, but no named arc membership table or legend that
would establish the app's groups. Neither colour nor proximity supplies an arc
name without interpretation.

[Black Library's Saga announcement](https://www.warhammer-community.com/en-gb/articles/17oswfuf/world-championships-preview-experience-the-greatest-hits-of-the-horus-heresy-saga-in-a-new-curated-series/)
provides the separate 12-book selection. It does not define the app's nine arcs.

## Result

The catalogue leaves story arcs unclassified. No alternate classification has
been invented or substituted. The manual names, book assignments, group colours,
filters, grouped collection, and lane views have been removed. Original source
links remain available for browsing the author's full guide.

Reference browsing defaults to an alphabetical list. Saga keeps the publisher's
listed order. The Connection map retains the sourced arrows on a neutral grid;
positions do not claim story arcs, chronology, or reading order. The existing
2019 connection snapshot and the Saga selection are unchanged by this audit.

Any future arc view needs a source record for its names and memberships. It must
allow overlapping memberships if the source shows them and leave unsupported
assignments unclassified.
