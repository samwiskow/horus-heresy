# Reference colour marks

Colour marks use the book plates in Daunt’s flowchart, version 0.9:
https://www.kylebb.com/HH/HHSeriesOrder.svg

The snapshot was retrieved on 1 October 2026. Its SHA-256 is
`206f298a1cb9146e9ed3d2c7a4b1e820b4369fa48eb72131e535f251802e3f16`.
The `fill` and `stroke` values are stored with all 173 matched reference nodes
in `src/sources/reference-flowchart.json`, under their original source IDs.
Values come from the embedded Draw.io model. Where that model omits a colour,
the rendered SVG supplies its white fill and black outline.

These are source node colours, not a distinct legion palette. For example, The First
Heretic and Know No Fear share brown, while Scars and The Path of Heaven have
different fills. No memberships or reading connections are inferred from them.

Small marks appear in the Connection map, Explore list, and My library.
Faction names remain visible. Books outside the 2019 source, including later
Siege volumes, receive no invented colour. Reading state still uses its own
written labels, symbols, and plate treatment.
